# Reliable Distributed Agent Systems

Distributed-systems rigor applied to autonomous AI infrastructure: agents that
cooperate across machines with consistent task state, tolerating crashes and
adversarial behavior, preventing duplicate actions, and producing verifiable
outcomes.

Built on: [Concurrent and Distributed Systems in Rust](https://github.com/luca-zanolini/distributed-systems-in-rust).

Status: Phase 0 — foundation map.
